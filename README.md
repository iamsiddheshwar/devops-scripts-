# DevOps Scripts

A collection of reusable Bash scripts for installing, configuring, and automating commonly used DevOps tools and services. This repository is designed to simplify environment setup and reduce the time required for manual configurations.

## About the Repository

This repository contains shell scripts that automate the installation and basic setup of various DevOps tools used in development and cloud environments.

The scripts are intended for learning, practice, and quick environment provisioning on Linux-based systems.

## Usage

Clone the repository:

```bash
git clone https://github.com/iamsiddheshwar/devops-scripts.git
```

Move into the repository:

```bash
cd devops-scripts
```

Provide execute permissions to the script:

```bash
chmod +x nginx.sh
```

Run the script:

```bash
./nginx.sh
```

For scripts that require administrative privileges, use:

```bash
sudo ./script-name.sh
```
